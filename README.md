💰 Personal Expense Tracker

A simple Personal Expense Tracker built using Python to help users record, manage, and track their daily expenses.

The project uses a JSON file to store expense data, so the records remain available even after closing the program.

🚀 Features

- ➕ Add new expenses
- 📋 View all expenses
- 🔍 Search expenses by category
- 💰 Calculate total expenses
- 📊 View category-wise spending summary
- ❌ Delete an expense
- 💾 Automatically save expenses in a JSON file
- 📅 Automatically record the expense date
- 🖥️ Simple command-line interface

🛠️ Technologies Used

- Python
- JSON
- File Handling
- Datetime
- OS Module

2. Open the project folder

cd expense-tracker-python

3. Run the program
